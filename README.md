# LogoMedo app

Flutter aplikacija (Android, iOS) za [logomedo.com](https://logomedo.com): zasad admin kataloga
slika po glasovima, kasnije interaktivne vježbenice za logopede.

```bash
flutter pub get
flutter run --dart-define-from-file=config/prod.json
```

Arhitektura: [docs/arhitektura.md](docs/arhitektura.md). API: `logomedo.com/docs/app-api.md`.
